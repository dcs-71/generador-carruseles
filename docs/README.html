Academy Carousel Generator

Aplicación Electron para generar carruseles educativos de Academy by Total Therapy usando Nano Banana Pro / Gemini image generation.

El flujo permite importar un CSV de ideas, generar colas de carruseles de 4 o 5 slides en formato 1:1, revisarlos, aprobarlos y exportar los PNGs finales.

Comando para lanzar la aplicación

npm start
Nota: Asegúrate de tener instaladas las dependencias con npm install antes de ejecutar el comando.
